# hide-a-hole

Нативная утилита macOS рисует чёрную подложку на уровне системного меню. Панель пропускает клики, высота соответствует исходной высоте меню-бара без поправки.

Из папки проекта:

```sh
swift run hide-a-hole install    # установить и запустить при входе в систему
swift run hide-a-hole status     # проверить регистрацию в текущей сессии
swift run hide-a-hole uninstall  # остановить и убрать из автозапуска
```

Установка копирует исполняемый файл в `~/Library/Application Support/hide-a-hole/` и создаёт пользовательский LaunchAgent в `~/Library/LaunchAgents/`. Повторная установка обновляет копию и перезапускает сервис. Автозапуск происходит после входа текущего пользователя, без прав администратора.

Для ручного запуска используйте `swift run hide-a-hole`; остановка — Ctrl+C. Одновременно ручной запуск и сервис не нужны. Утилита не показывает окно или значок в Dock. При автоматически скрытом меню-баре высота панели может определяться неверно.
